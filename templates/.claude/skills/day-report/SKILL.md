# 완료 보고서 작성

> 이 스킬은 `CLAUDE.md` 「세션 종료 프로토콜」 1·2항의 실행 절차다.
> 종료 프로토콜 전체(MEMORY 갱신·이슈 처리·커밋·작업 표면 상태)는 `CLAUDE.md` 에 있다.

**두 문서를 모두 만든다 — 하나로 합치지 않는다.**

| 문서 | 대상 | 성격 |
|---|---|---|
| `sessions/day-XX.md` | 다음 세션의 나 | 개발 기록 |
| `briefing/day-XX-report.html` | 결정권자 | **읽고 결정을 내리는 문서** |

## 보고서 — `briefing/day-XX-report.html`

**반드시 담을 5가지**

| # | 절 | 내용 |
|---|---|---|
| 1 | **작업 전 / 작업 후** | 나란히 대조. 무엇이 없었고 무엇이 생겼는지 |
| 2 | **전체 진전도** | n/N, 다음 마일스톤, 핵심 수치 타일 |
| 3 | **발견 / 검증** | 조사로 뒤집힌 전제, 게이트 결과 |
| 4 | **결정사항** | 사람이 정할 것. **선택지 + 권장안 + 각 선택의 비용** |
| 5 | **남은 오류·미검증** | 이월 이슈, **"언제 문제되나"** 를 반드시 함께 |

**작성 원칙**

- **비개발자 어휘로 쓴다.** 기술 용어가 꼭 필요하면 바로 옆에 풀어 쓴다
- **결정사항은 "정해주세요"로 끝내지 않는다.** 선택지 A·B, 권장안 표시, 각 선택의 비용을
  적어야 그 자리에서 정할 수 있다
- **남은 오류는 "언제 드러나는지"가 핵심이다.** "지금은 무해하지만 배포에서 터진다"까지
  적어야 우선순위를 정할 수 있다
- 단일 HTML. **외부 리소스를 불러오지 않는다**(CSS 인라인). 라이트/다크 양쪽 대응
- 표는 `overflow-x:auto` 컨테이너 안에 둔다 — 좁은 화면에서 페이지가 가로로 밀리면 안 된다

**띄우는 법** — 만든 뒤 반드시 **orca 브라우저 탭**으로 연다. OS 기본 열기(`open` 등)는 쓰지 않는다
(orca 밖 기본 브라우저로 열려 맥락에서 떨어지고, orca 가 기본 브라우저면 탭이 중복 생성된다).

```bash
orca tab create --worktree active --url "file:///$(pwd)/briefing/day-XX-report.html" --json   # --focus 는 붙이지 말 것
orca tab list --worktree active          # 확인 (중복이면 orca tab close --page <id>)
```

## sessions/day-XX.md 템플릿

```markdown
# Day XX (계획 M/D 요일 · 실제 수행 YYYY-MM-DD 요일)

## 목표
(오늘 계획했던 것)

## 한 일
- [x] 완료 항목 (이슈 #N)
- [ ] 미완 항목 → 사유

## 결정한 것
- 무엇을 왜 그렇게 정했는지 (다음에 번복하지 않도록)

## 막힌 것 / 리스크
- 현상 · 원인 추정 · 시도한 것

## 사람이 해줘야 할 일 (인프라 요청)
- [ ] 계정/키 발급 등

## 다음 세션이 이어받을 것
- 가장 먼저 할 일 1~3개 (구체적으로 — 파일 경로까지)
```

⚠️ 제목에는 **계획일과 실제 수행일을 병기**한다.
실제 수행일은 `date '+%Y-%m-%d (%a)'` 로 얻는다. 계획표를 보고 적지 않는다.

## 비개발자 용어 대조표  ← 프로젝트 용어를 추가한다

| 개발 용어 | 보고용 표현 |
|---|---|
| API | 화면에 데이터를 넘겨주는 창구 |
| 스키마 · 마이그레이션 | 데이터를 담을 표(테이블)를 설계하고 반영하는 일 |
| 파이프라인 · 배치 | 정해진 시각에 자동으로 도는 데이터 처리 |
| CI | 코드를 올릴 때마다 자동으로 도는 검사 |
| 커버리지 | (수치를 그대로 쓴다 — 풀어 쓰면 오히려 모호해진다) |
| E2E · 통합 테스트 | 처음부터 끝까지 한 바퀴가 도는지 확인하는 것 |
| 폴백 | 데이터가 부족할 때 대신 보여주는 간단한 형태 |
| 리팩터링 | 동작은 그대로 두고 코드를 정리하는 일 |
| 마스킹 · 트렁케이션 | 유료·비공개 구간을 서버에서 아예 안 내려주는 처리 |

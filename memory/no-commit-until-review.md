작업 내용은 중간에 커밋하지 않는다. 모든 작업이 끝나면 태홍님께 검수를 받고 **커밋 허락을 받은 뒤에만** 커밋한다 (2026-09-28, #190 관심지역 AI예측 작업 중 지시).

**Why:** 2026-09-28 에 scorer 브랜치에 로컬 커밋(미푸시)을 먼저 만들었다가 이 지시를 받고 `reset --soft` 로 되돌렸다. 태홍님은 결과물을 직접 검수한 뒤 저장소 기록에 남기길 원한다.
**How to apply:** TDD·게이트 진행 중에도 변경은 워킹트리에만 둔다. 완료 보고 시 변경 파일 목록·diff 요약·테스트 결과를 제시하고 「커밋할까요?」로 허락을 구한다. push·PR 은 당연히 그 이후. **push 전에는 반드시 `git fetch` 로 원격 최신을 받아 새 커밋·겹치는 파일(충돌)을 확인**하고, 기준을 최신으로 올린 뒤 테스트를 다시 돌린다(태홍님 지시 9/28 — 팀원이 같은 main 에 직접 커밋하는 저장소에서 특히 중요하다). 저장소 기록은 태홍님 계정만([[git-identity-noreply]]).

# 전역 사용자 지침 (모든 프로젝트·세션 공통)

> 이 파일은 모든 프로젝트에 로드되는 최상단 사용자 지침이다.

## 호칭 / 어투
- 사용자를 **"태홍님"** 으로 호칭한다.
- 상호 **존댓말(존칭)** 로 응대한다. ("너/네" 등 반말 2인칭 호칭은 쓰지 않는다.)

## 커밋 · PR 작성자 표기 (필수)
- 커밋 메시지와 PR 본문에 **Claude 관련 표기를 절대 넣지 않는다.**
  - `Co-Authored-By: Claude ...` 트레일러 금지
  - `🤖 Generated with [Claude Code]` 류의 PR 본문 문구 금지
- 저장소 기록에는 **태홍님 계정만** 남아야 한다.
- 하네스 차원에서도 차단되어 있다 — `~/.claude/settings.json` 의
  `attribution: { commit: "", pr: "" }` 및 `includeCoAuthoredBy: false`.
  설정이 초기화되더라도 이 지침이 남아 규칙은 유지된다.

## 상태 보고 및 로그
- 모든 상태 업데이트, 로그, 진행 상황 보고 앞에 `[HH:MM]` 형식의 타임스탬프를 붙인다.
- 예: `[15:23] 고의 실패 커밋 푸시 완료 — CI 감시 중`
- 자리를 비웠다가 돌아왔을 때 진행 상황 파악을 위함

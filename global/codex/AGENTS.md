# 전역 사용자 지침 (모든 프로젝트·세션 공통)

> 이 파일은 모든 프로젝트에 로드되는 최상단 사용자 지침이다.

## 호칭 / 어투
- 사용자를 **"치타홍님"** 으로 호칭한다.
- 상호 **존댓말(존칭)** 로 응대한다. ("너/네" 등 반말 2인칭 호칭은 쓰지 않는다.)

## 상태 보고 및 로그
- 모든 상태 업데이트, 로그, 진행 상황 보고 앞에 `[HH:MM]` 형식의 타임스탬프를 붙인다.
- 예: `[15:23] 고의 실패 커밋 푸시 완료 — CI 감시 중`
- 자리를 비웠다가 돌아왔을 때 진행 상황 파악을 위함
